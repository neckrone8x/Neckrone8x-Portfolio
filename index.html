ESP32 RGB Controller

A web-based RGB LED controller built with an ESP32. The system allows the LED to be controlled remotely through a web interface.

ESP32HTMLCSSWiFi

The Problem

Wanted to control room lighting without a physical switch or app install.

An ESP32-hosted web server that serves a control page over local WiFi, with sliders for RGB channels and preset scenes.
